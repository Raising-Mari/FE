# 디자인 시스템 정리

Figma 「AI리터러시경진대회」 파일의 **디자인 시안** 페이지(1440px 데스크톱 화면 25장, 노드 3,802개)에서 색·글자·부품을 뽑아 합친 기록이다. 코드에 들어간 값은 `src/styles/index.css`의 `@theme`가 원본이고, 이 문서는 "시안의 어떤 값을 어느 토큰으로 합쳤는지"를 남긴다. 개발 서버에서 `/styleguide`를 열면 같은 내용을 화면으로 본다. 팀이 함께 보는 원본은 Figma의 「컴포넌트 & 색정의 & 타이포그래피」 페이지이고, 새 색·스타일·부품은 거기에 먼저 넣은 뒤 코드에 반영한다.

## 1. 글꼴

| 시안 | 코드 |
|---|---|
| LevelUp(대부분), Chai Hwaljjak TTF, SEBANG GOTHIC 2.0이 섞여 있음. 모두 Regular(400)뿐 | **세방고딕 2.0 하나로 통일** |

- 파일: `src/assets/fonts/SebangGothic-Regular.woff2`(287KB), `SebangGothic-Bold.woff2`(291KB). 원본은 `SEBANG_GOTHIC_2.0_Fonts/WebFont/`.
- Light·Italic은 시안에 없어 넣지 않았다. Bold는 시안에서 안 쓰지만, 없으면 브라우저가 가짜 굵기를 만들어서 함께 둔다.
- `font-display: swap`. 폰트 용량은 합쳐서 약 580KB(WOFF2).
- 세방고딕에 **없는 글리프**: `⌂ ◉ ✎ ⚑ ◷ ⚙ ✦ ⌄`. 시안의 메뉴 아이콘이 이 글자들이라 기기마다 다른 글꼴로 그려진다(⚙는 이모지로 나올 수 있음). → 6번 항목 참고.

## 3. 글자 크기

### 아직 만들지 않은 시안 요소
화면을 만들면서 두 곳 이상에서 쓰이면 `components/ui`로 올린다. 한 화면에서만 쓰이면 해당 `features/<기능>/components`에 둔다.

`button.course`(과목 선택 상자) · `div.history-row`(기록 줄) · `button.unit-row` / `button.week`(주차 줄·탭) · `div.versus`(대결 패널) · `div.resultscore`(점수) · `div.note`(노트 줄) · `details.demo-tools`(시연 도구) · 채팅 말풍선(`div.msg`) · 랭킹 줄(`div.rankrow`) · `div.sidebottom`(사이드바 하단 안내).

## 6. 결정이 필요한 것

1. **마리 캐릭터 이미지 — 해결됨(2026-11-11).** 시안의 마리는 이미지 생성 AI로 만든 그림이다. 대회 규정이 막는 것은 미리캔버스·캔바 같은 템플릿 디자인 툴이고 이미지 생성 AI는 써도 되므로, 시안의 그림을 그대로 쓴다. 그림은 화면을 만들 때 해당 자리의 Figma 노드에서 내려받아 `src/assets/mari/`에 둔다(헤더 로고는 이미 들어가 있다). 필요한 자리는 8곳이다(시안은 이미지 3장에서 잘라 썼다).

   | 시안 이름 | 크기(px) | 나오는 화면 |
   |---|---|---|
   | 차분하게 서 있는 마리 (헤더 로고) | 42×51 | 전 화면 헤더 |
   | 책과 소품 사이에서 떠오르는 마리 (첫 화면 큰 그림) | 420×420 | 01 시작 랜딩 |
   | 꽃을 들고 반기는 마리 | 255×261 | 02 로그인, 03 가입 |
   | `div.mari-banner`의 마리 | 110×77~105 | 04–07, 12–25 (배너가 있는 화면 대부분) |
   | `div.scene`의 마리 | 135×138 | 08, 09 (가르치기) |
   | `div.versus`의 마리 (내 마리·상대 마리) | 170×168, 170×205 | 13–16 (배틀 대기·결과 대기·오류) |
   | 뒤돌아 자료를 살펴보는 마리 | 110×120 | 10, 11 (자료 목록·연결) |
   | `div#loadingMari` (결과 기다리는 중) | 150×154 | 15 |
2. **아이콘.** 시안 메뉴 아이콘이 글자 기호(`⌂ ◉ ✎ ⚑ ◷ ⚙`)라서 세방고딕에 글리프가 없다. 직접 그린 SVG 아이콘으로 바꿀지 정해야 한다. `NavItem`은 `icon`에 아무 노드나 받는다.
3. **모바일 시안이 없다.** 시안은 1440px뿐이다. 부품은 데스크톱 값을 기준으로 하되, 좁은 화면에서는 눌리는 영역 44px, 입력 글자 16px(iOS 확대 방지), 카드 안쪽 여백 축소만 더했다. 모바일 화면 구성은 시안이 있어야 정해진다.
4. **글자가 작고 대비가 낮다.** 본문 12px, 보조 설명 10~11px이고 `subtle`(`#8892a1`)은 흰 바탕에서 대비가 약 3:1이다(WCAG AA 4.5:1 미달). 시안 그대로 옮겼다. 고칠지는 디자인과 정한다.
5. **오류 색**(`danger`)이 시안에 없다. 2번 항목의 "시안에 없는 임시 색" 참고.
6. **서비스 이름.** 시안은 "마리 키우기", `index.html` 제목은 "AI 제자", 흐름도는 이름 후보를 받는 중이다. 화면에 나오는 이름은 `lib/brand.ts` 한 곳에서만 쓴다.
7. **Figma 정리 — 해결됨(2026-11-11).** Figma의 「컴포넌트 & 색정의 & 타이포그래피」 페이지에 같은 내용을 정리했다. 변수 컬렉션 `색정의`·`모서리`·`글꼴`, 글자 스타일 `텍스트/…`, 효과 스타일 `그림자/…`, 컴포넌트 12종이다. 변수 설명의 "코드:"가 이 문서의 토큰 이름이다. 이 연결 환경에서는 세방고딕을 불러올 수 없어 글꼴 변수 `font/family/sans`를 임시로 Noto Sans KR로 두었으니, 세방고딕이 설치된 컴퓨터에서 그 값을 `SEBANG GOTHIC 2.0`으로 바꿔야 한다.

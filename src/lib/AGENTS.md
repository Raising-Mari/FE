# src/lib/ — 순수 유틸·설정

- React에 의존하지 않는 함수·상수만 둔다. (날짜 변환, 문자열 처리, 환경설정)
- `env.ts`: 환경변수를 읽는 **유일한 곳**. 새 `VITE_` 변수를 쓰려면 `env.ts`, `vite-env.d.ts`, `.env.example`을 같이 고친다.
- 시각은 서버에서 UTC로 오므로 **화면에 보여 줄 때 한국 시간(Asia/Seoul)으로 변환**하는 함수를 여기 한 곳에 만들어 쓴다.
- 순수 함수는 테스트하기 쉽다. 로직이 생기면 `*.test.ts`를 옆에 같이 둔다.

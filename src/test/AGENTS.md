# src/test/ — 테스트 공통 설정

- `setup.ts`는 모든 테스트 전에 실행된다: jest-dom 매처, MSW 서버 시작·초기화, 화면 정리(cleanup).
- 처리되지 않은 요청은 에러(`onUnhandledFrame: error`)로 둔다. 테스트가 실제 네트워크로 나가지 않게 하기 위함이다.
- 개별 테스트에서 응답을 바꿔야 하면 `server.use(...)`로 그 테스트에서만 덮어쓴다.
- `renderApp(path)`: 로그인한 상태로 앱 전체(라우터·가드·틀·알림)를 주소 하나에서 띄운다. 기능 화면 테스트는 이것으로 쓴다.
- `resetAppState()`: 저장소·시나리오·알림·목업 데이터를 처음으로 돌린다(`setup.ts`가 테스트마다 부른다). 라우터를 import하지 않는 파일에 따로 있다 — setup에서 화면을 먼저 불러오면 테스트 파일의 `vi.mock`이 먹지 않는다.
- 이 폴더에는 공통 설정·헬퍼만 둔다. 테스트 파일 자체는 대상 옆(`*.test.tsx`)에 둔다.

# src/components/layout/ — 페이지 틀

- 화면 전체 틀(헤더, 왼쪽 메뉴, 본문 폭, 하단 줄)만 담는다.
- **데스크톱 전용**(시안 1440px)이다. 좁은 화면용으로 남아 있는 `md:`·`lg:` 분기와 가로 메뉴 줄은 단계 1(공통 기반)에서 정리한다. `100vh` 대신 `100dvh`를 쓴다.
- 로그인 상태에 따라 보이는 메뉴가 달라지는 경우에도 판단은 상위(라우터 가드)에서 하고, 여기는 받은 대로 그린다.

## 지금 있는 틀
- `AppShell`: 로그인 뒤 화면. 헤더(78px) + 왼쪽 메뉴(218px) + 본문.
- `PublicShell`: 로그인 전 화면(첫 화면·로그인·가입). 가운데 정렬 1200px.
- `Brand`: 헤더 왼쪽 마리 그림 + 서비스 이름(이름은 `lib/brand.ts`).
- `NavItem`: 메뉴 한 항목. 현재 주소와 맞으면 활성 표시.
- `AppLayout`: 지금은 임시 홈용 간단한 틀이다. 첫 실제 화면을 만들 때 `AppShell`로 바꾼다.

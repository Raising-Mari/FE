# features/teaching — 가르치기와 제자 노트  ★ 핵심 화면

## 규칙
- 화면은 **채팅 + 제자 노트 패널**이다. 모바일에서는 탭 또는 바텀시트로 전환한다.
- **노트는 읽기 전용이다.** 노트를 직접 편집·삭제하는 입력창이나 버튼을 만들지 않는다. 고치려면 대화로 다시 말하게 안내한다.
- 노트는 서버가 반영한 것만 보여 준다. 학생이 입력한 말을 FE가 임의로 노트에 미리 넣지 않는다.
- 서버가 노트 변경을 일부 반려한 경우(`rejectedCount`)에는 "이 부분은 노트에 담기지 않았어요. 더 구체적으로 설명해 보세요"처럼 **설명을 보완하도록** 안내한다.
- AI 응답은 몇 초 걸린다. 전송 중 상태(로딩, 중복 전송 방지)와 실패 시 재전송을 반드시 만든다.
- 제자의 되묻는 질문("왜 그런가요?")은 학생이 다음 입력을 하기 쉽도록 입력창 가까이에 보이게 한다.
- 대화 내용은 개인정보가 될 수 있으니 콘솔에 출력하지 않는다.

# features/review — 복기·노트 교환 리뷰·신고

## 규칙
- 복기 화면은 틀린 문항마다 **제자의 답 / 근거가 된 노트 / 강의자료 근거 문장**을 나란히 보여 준다. (모바일은 세로로 쌓되 순서를 유지)
- 오답 원인은 세 가지(노트에 없음 / 노트가 틀림 / 노트는 맞는데 제자가 적용 못함) 중 학생이 직접 고른다. 서버의 자동 분류는 **"제안"**으로만 표시하고 선택을 대신하지 않는다.
- "문제가 이상해요" 신고와 AI 진단 이의제기 버튼을 복기 화면에서 바로 누를 수 있게 한다.
- 상대 노트는 상대가 공개에 동의한 경우에만 서버가 내려준다. 못 받은 경우 "공개되지 않은 노트"로 안내한다.
- 리뷰 작성 시 "좋았던 점"과 "보완할 점"을 따로 입력받고, 근거(노트의 어느 부분인지)를 함께 쓰도록 유도한다.

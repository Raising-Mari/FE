# features/review — 결과·복기·연습 배틀·신고·노트 교환 리뷰

## 규칙
- 복기(R-01)는 끝난 **랭킹 배틀**에서만 열린다. 맞히지 못한 문항(오답·부분 정답·모름·판정 실패)과 채점 조작 의심으로 0점이 된 문항을 앞에 두고, 맞힌 문항은 접어서 아래에 둔다(연습 대상으로 고를 수 있게).
- 문항마다 **제자의 답 / 근거가 된 노트**를 나란히 보여 준다. **모범 답과 강의자료 근거 문장은 "정답 보기"(R-11)를 누르기 전까지 숨긴다.** 응답에도 없으니 화면에서 만들어 내지 않는다. 정답 보기는 되돌릴 수 없고 이 배틀의 연습이 끝난다는 확인 창을 거친다. 연 뒤에는 모범 답·자료 근거까지 3칸으로 보여 준다.
- 오답 원인은 **5가지**(가르치지 않음 `NOT_TAUGHT` / 노트에 없음 `NOT_IN_NOTES` / 노트가 틀림 `NOTE_WRONG` / 노트는 맞는데 제자가 못 씀 `NOT_APPLIED` / 기타 `OTHER`) 중 학생이 직접 고른다(R-02, 정답 보기 전에도 후에도 저장·수정 가능). 서버의 자동 분류(`causeSuggestion`)는 **"제안"**으로만 표시하고 선택을 대신하지 않는다. 맞힌 문항에는 원인 선택이 없다.
- 채점 조작 의심으로 0점이 된 문항에는 "채점 조작 의심으로 0점 처리됨" 배지와 이의제기(R-03 `GRADING`) 버튼을 보이되, 어떤 패턴이 걸렸는지는 보여 주지 않는다.
- 신고는 복기 화면에서 바로 누를 수 있게 한다: "문제가 이상해요"(R-03 `QUESTION`)와 채점 이의제기(`GRADING`). 같은 답·같은 종류는 한 번만(`REPORT_DUPLICATE`).
- **연습 배틀**(B-10): 랭킹 배틀의 복기에서만 시작하고 혼자 푼다. 복기에서 고른 답의 **원래 문항을 그대로** 현재 노트로 다시 풀며 랭킹에 반영되지 않는다. 틀린 문항은 미리 체크, 맞힌 문항도 직접 고를 수 있다. 건너뛴 답(`skippedAnswerIds`)을 안내하고, 정답을 이미 열었으면(`PRACTICE_ANSWERS_REVEALED`) 시작할 수 없다고 안내한다. 정답을 열기 전에는 횟수 제한이 없다(사용량 제한만).
- **연습 결과**(B-07 `mode=PRACTICE`)는 문항마다 "이전 답 → 이번 결과"(`retestOf`)를 보여 주고 정답은 보여 주지 않는다. "다시 연습" 버튼은 없다(연쇄 금지). "원래 배틀 복기로"(`sourceBattleId`)와 "노트 고치러 가기"만 둔다.
- **노트 교환 리뷰**(R-06~R-08, 서버에 없으면 목업 `api/pending.ts`): 두 사람이 모두 공개에 동의한 경우에만 상대 노트가 보인다. 못 받으면(`REVIEW_NOTES_NOT_PUBLIC`) "공개되지 않은 노트"로 안내한다. 리뷰는 "좋았던 점"과 "보완할 점"을 따로 입력받고 근거 노트(`evidenceNoteEntryId`)를 고르게 한다. 배틀당 1회(`REVIEW_ALREADY_SUBMITTED`).

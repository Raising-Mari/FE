# features/admin — 운영·문제 은행·신고 (시안 25)

- `RequireAdmin` 아래에서만 열린다. 서버도 관리자가 아니면 403을 준다.
- 이 화면에는 문항의 **정답·근거가 보인다**. 학생 화면·공용 부품·전역 상태로 이 데이터를 넘기지 않는다.
- 문항 상태 변경은 서버가 받아 주는 것만 버튼으로 둔다(`api.ts`의 `NEXT_STATUSES`). 신고 처리 상태로 `OPEN`은 보내지 않는다.
- 주차 선택은 왼쪽 메뉴에서 고른 과목의 주차다(`app/routeElements.tsx`의 `AdminRoute`가 넘긴다).
- "미판정 문항 사용" 스위치는 만들지 않는다(서버 설정, 팀 결정).
- 통계는 서버가 센 값을 그대로 보여 준다. CSV에는 개인을 알아볼 값이 없다.

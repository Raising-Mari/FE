# features/battle — 배틀 방·대기실·진행·오류

## 규칙
- 배틀은 **비동기 + 폴링**이다 (웹소켓 없음). 상태는 `useQuery`의 `refetchInterval`(2~3초)로 확인한다. **`FINISHED`·`CANCELED`·`EXPIRED`에서만 폴링을 멈추고, `ERROR`에서는 계속한다.** (상대가 다시 시도하거나 포기하는 것을 따라가야 한다)
- 방 상태 7가지(`WAITING` · `LOBBY` · `RUNNING` · `FINISHED` · `CANCELED` · `EXPIRED` · `ERROR`)마다 화면을 만든다. `ERROR`에서는 "다시 시도"(B-09, `RUNNING`으로 복귀)와 "포기하고 나가기"(B-05, `CANCELED`, Elo 불변)를 **참가자 누구나** 누를 수 있다. 취소(B-05)도 `WAITING`·`LOBBY`에서 참가자 누구나 할 수 있고 방 전체가 닫힌다.
- 방 만들기: 주차 1개, 문제 수 3~10(기본 5), Q-01로 문제가 모자라는지 미리 안내한다. **내 노트가 0개인 주차(`myNoteCount`)는 방을 만들 수 없다** — 버튼을 비활성하고 "먼저 가르치러 가기"를 안내한다(서버도 `BATTLE_NOTES_REQUIRED`).
- 방 코드(6자리) 입력은 대소문자·공백을 정리해 보낸다. **링크 입장**: `/join/<코드>`로 열면 자동으로 입장(B-02)하고, 대기실에 코드 복사·링크 복사 버튼을 둔다.
- **노트 공개 동의**: 서버는 B-04(준비 완료)의 **첫 호출에서만** `notesPublic`을 받는다(방 만들기 요청에는 없다). 방 만들기·입장 화면의 체크 값을 기억했다가 준비 완료를 누를 때 같이 보낸다. 나중에 바꾸기는 B-08. 두 사람이 모두 동의해야 서로의 노트가 보인다.
- **준비 완료**는 `LOBBY`(상대가 들어온 뒤)에서만 누를 수 있다. 누른 순간의 내 노트가 이 배틀에 쓰이고 이후 노트를 고쳐도 반영되지 않는다고 안내한다. 멱등이라 연타해도 안전하지만 버튼은 막는다. 문제가 모자라면(`BATTLE_NOT_ENOUGH_QUESTIONS`) 로비에 머물고 두 사람의 준비가 풀린다 → "방을 취소하고 문제 수를 줄여 다시 만들어 주세요".
- 오류 코드별 안내: `BATTLE_ROOM_NOT_FOUND`·`FULL`·`EXPIRED`·`SELF_JOIN`, `BATTLE_DISCIPLE_REQUIRED`(제자 만들기로 안내), `BATTLE_NOTES_REQUIRED`(오류 본문의 주차 이름으로 가르치러 가기 안내), `BATTLE_ALREADY_ACTIVE`, `BATTLE_QUESTION_BANK_NOT_READY`, 허용되지 않은 전이(409).
- 배틀이 진행되는 동안 문제 원문·정답·상대 노트는 화면에 없다(응답에도 없다). 결과 화면에서도 서버가 내려준 것만 보여 준다.
- 채점·Elo 계산은 서버 몫이다. FE에서 점수를 계산하지 않는다.
- 새로고침·뒤로가기를 해도 현재 배틀 상태를 서버에서 다시 받아 이어서 보여 준다.
- 시안의 "시연 도구"(상대·오류 상태 흉내 패널)는 MSW 모드(`VITE_USE_MOCK=true`)에서만 보인다.

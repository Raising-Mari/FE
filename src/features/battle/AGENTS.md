# features/battle — 배틀 로비·진행·결과

## 규칙
- 배틀은 **비동기 + 폴링**이다 (웹소켓 없음). 대기·채점 상태는 `useQuery`의 `refetchInterval`로 확인하고, **종료 상태가 되면 폴링을 멈춘다.**
- 방 코드(6자리) 입력은 대소문자·공백을 정리해 보내고, 잘못된 코드·가득 찬 방은 `ApiError.code`별로 안내한다.
- 배틀이 진행되는 동안 문제 원문·정답은 화면에 없다. 결과 화면에서도 서버가 내려준 것만 보여 준다.
- 채점·Elo 계산은 서버 몫이다. FE에서 점수를 계산하지 않는다.
- 새로고침·뒤로가기를 해도 현재 배틀 상태를 서버에서 다시 받아 이어서 보여 준다.

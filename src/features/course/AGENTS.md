# features/course — 과목·자료 업로드·단원 선택

## 규칙
- 업로드 화면에는 **"본인이 사용 권한을 가진 자료만, 개인정보 제외"** 안내와 **동의 체크박스**가 있어야 하고, 동의 전에는 업로드 버튼이 눌리지 않는다.
- 자료 처리는 오래 걸릴 수 있다. 업로드 후 상태(`PENDING / DONE / FAILED`)를 주기적으로 확인(`refetchInterval`)하고, 끝나면 멈춘다.
- **단원은 학생이 직접 정한다.** 서버가 정해 주거나 개념 목록을 보여 주는 UI를 만들지 않는다.
- 자료에서 뽑은 개념 목록·문항은 서버도 주지 않지만, 화면에서도 어떤 형태로든 노출하지 않는다.
- 파일은 업로드 전에 확장자·크기를 먼저 검사해 바로 알려 준다. (서버 검사가 최종이다)

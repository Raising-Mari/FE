# features/course — 과목·제자·주차·자료

## 규칙
- **과목은 학교 안에서 공유된다.** 새 과목 만들기는 이름을 입력하면 같은 학교의 기존 과목을 검색(C-01)해 보여 주고, 고르면 그 과목에 참여(제자 만들기 = 수강 등록), 없으면 새로 만든다(C-02, 학기는 현재 학기 `YYYY-N`을 자동으로 넣는다). 이미 있으면(`COURSE_DUPLICATE`) 오류의 `details.existingCourseId` 과목으로 이동한다.
- **과목마다 제자는 한 명**이다(D-01, `DISCIPLE_ALREADY_EXISTS`). 제자가 없는 과목에서는 가르치기·배틀에 들어갈 수 없게 안내한다.
- **단원 = 주차.** 주차는 과목 안에서 학생들이 함께 쓰고 학생이 직접 만든다(C-06, 같은 이름이면 기존 주차 `UNIT_DUPLICATE`). 서버가 주차를 정해 주거나 개념 목록을 보여 주는 UI를 만들지 않는다.
- **자료는 선택이다.** 자료 없이 주차만 있어도 가르칠 수 있다. 자료는 과목에 먼저 올리고(M-01 PDF / M-02 붙여넣기) 나중에 여러 주차에 연결한다(M-06, 자료 전체가 출처). 연결을 풀면 그 자료를 근거로 한 문제가 배틀에서 빠진다는 안내를 보여 준다.
- 업로드 화면에는 **"사용 권한이 있는 자료이고 개인정보를 제외했으며, 같은 과목 학생에게 근거 문장 일부가 보일 수 있다"** 안내와 **동의 체크박스**가 있어야 하고, 동의 전에는 저장 버튼이 눌리지 않는다.
- 파일은 업로드 전에 확장자(PDF)·크기(20MB 이하)를 먼저 검사해 바로 알려 준다. (서버 검사가 최종이다)
- 자료 처리는 오래 걸릴 수 있다. 상태(`PENDING` → `PROCESSING` → `DONE`·`FAILED`)를 `refetchInterval`로 확인하고 `DONE`·`FAILED`에서 멈춘다. 실패 이유(`NO_TEXT` 스캔본, `TOO_LARGE`, `PARSE_ERROR`, `SERVER_RESTART`)별로 안내한다.
- 자료에서 뽑은 개념 목록·문항은 서버도 주지 않지만, 화면에서도 어떤 형태로든 노출하지 않는다. 주차에는 내 노트 수(`myNoteCount`)와 배틀 가능 여부(`battleReady`)만 보여 준다. (시안의 "문제 N개" 같은 표시는 만들지 않는다)
- 자료 삭제(M-05)는 서버에 없으면 버튼을 숨긴다(`api/pending.ts`).

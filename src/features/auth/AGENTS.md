# features/auth — 로그인·학교 메일 인증

## 화면 흐름
학교 메일 입력 → 인증 코드 입력 → 닉네임 정하기.

## 규칙
- 토큰은 `stores/authStore`에 둔다. 어디에 저장(메모리/localStorage)할지는 구현 전에 팀이 정한다. 정해지기 전에는 localStorage에 토큰을 쓰지 않는다.
- 인증을 마치지 않은 사용자는 배틀·랭킹 화면에 들어올 수 없게 라우트 가드를 둔다. (서버도 막지만 화면에서도 안내한다)
- 인증 코드 재전송에는 대기 시간을 보여 준다. 실패 이유(`ApiError.code`)별로 안내 문구를 나눈다.
- 이메일·인증 코드를 콘솔에 출력하지 않는다.

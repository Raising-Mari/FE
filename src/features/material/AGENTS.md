# features/material — 학습 자료 (시안 10·11)

- 자료는 **과목에 올리고 주차는 나중에 고른다**. PDF(M-01)를 고르면 파일로, 아니면 붙여넣은 글(M-02)로 올린다. 동의 체크가 켜져야 저장할 수 있다(서버도 `MATERIAL_CONSENT_REQUIRED`로 검사).
- 올리기 전에 확장자(.pdf)·크기(20MB)·빈 파일을 먼저 알려 준다. 기준값은 `api.ts`의 상수 한 곳에 둔다.
- 접수(202) 뒤 처리는 서버가 따로 한다. 목록(M-04)에 처리 중인 자료가 있는 동안만 2.5초마다 다시 받는다. 실패 이유는 목록에 없어서 실패한 자료만 M-03으로 묻는다.
- 문항 수·문장 내용은 서버가 주지 않으므로 보여 주지 않는다(시안의 "문제 24개"는 뺐다).
- 삭제(M-05)는 서버에 아직 없다. 버튼은 두고 404·405면 "아직 지원하지 않는 기능"으로 안내한다(`api/pending.ts`).
- 주차 연결(M-06)은 통째로 바꾼다. 연결을 풀면 그 출처의 문제가 배틀에서 빠진다고 알린다.

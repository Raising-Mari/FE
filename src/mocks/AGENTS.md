# src/mocks/ — MSW 목업

BE가 아직 없거나 BE 없이 화면을 만들 때, 그리고 테스트에서 서버 응답을 흉내 낸다.

## 규칙
- `handlers.ts`가 브라우저(`browser.ts`)와 테스트(`server.ts`)에서 **같이** 쓰인다. 핸들러는 여기에만 둔다.
- 경로·필드 이름·에러 모양은 **BE의 Swagger와 똑같이** 맞춘다. 목업이 실제와 다르면 연동할 때 화면이 깨진다.
- 목업 데이터에 실제 학생 정보·실제 강의자료를 넣지 않는다.
- 문제 은행의 문항·정답은 목업에도 넣지 않는다. (학생에게 숨겨야 하는 정보)
- 켜고 끄기는 `.env`의 `VITE_USE_MOCK`으로만 한다. 이 값이 `false`면 목업 코드는 실행되지 않는다.

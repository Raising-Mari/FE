# public/ — 정적 파일

빌드 없이 그대로 서비스되는 파일(`/favicon.svg` 같은 주소로 접근). 코드에서 import해 쓰는 이미지는 `src/assets/`에 둔다.

## 규칙
- **`mockServiceWorker.js`는 MSW가 만든 파일이다. 직접 고치지 않는다.** (MSW 버전을 올리면 `npx msw init public/`로 다시 만든다)
- 제자 캐릭터 그림처럼 우리가 직접 그린 이미지만 올린다. 이미지·영상 생성 AI로 만든 그림은 쓰지 않는다 (대회 규정).
- 저작권이 불분명한 이미지·폰트를 올리지 않는다.
- 파일 하나는 가능하면 200KB 이하로 줄인다. (모바일 로딩 속도)
